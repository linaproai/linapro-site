# 架构

LinaPro 由四个彼此配合、但职责不重叠的层次组成。

## 1. 核心宿主服务

宿主是稳定的后端底座，负责：

- API 契约
- 服务治理
- 认证与 RBAC
- 插件生命周期编排
- 供插件依赖的稳定平台接缝

宿主不应该变成承载所有业务模块的大一统层。

## 2. 默认管理工作台

默认工作台是生产可用的 Vue 3 操作界面。它消费宿主 API、渲染核心模块，并托管插件页面。

这是一套参考操作界面，而不是 LinaPro 全部产品边界的定义。

## 3. 插件运行时

LinaPro 通过插件让宿主保持克制。

- **源码插件** 通过显式注册参与构建。
- **动态 WASM 插件** 面向受治理的运行时交付场景。

这使得模块可以独立演进、按需组合，也更容易被替换。

## 4. OpenSpec 工作流

工作流位于代码之上：

```text
Explore -> Propose -> Implement -> Review -> Archive
```

每次迭代都会沉淀出 AI 和人类都能继续消费的工件。

## 设计原则

- **宿主稳定**：保持地基通用且耐久。
- **模块级松耦合**：业务模块通过接缝协作，而不是隐式依赖。
- **治理显式化**：权限、生命周期和评审门禁都应该是一等概念。
- **规范驱动迭代**：先解释变化，再合入变化。
