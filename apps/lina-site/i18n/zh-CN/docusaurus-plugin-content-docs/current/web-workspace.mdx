# 默认工作台

`apps/lina-vben/apps/web-antd` 是 LinaPro 的默认管理工作台。

## 它的角色

这个工作台：

- 通过 `/api/v1` 消费宿主 API
- 渲染内建管理能力
- 托管插件感知页面与路由
- 作为系统治理的默认操作入口

## 工作台内建了什么

默认工作台已经覆盖常见平台场景：

- 用户、角色、菜单管理
- 字典、参数、文件管理
- 任务、分组、执行日志
- 插件管理
- API 文档与系统信息

## 为什么这很重要

LinaPro 不只是后端运行时，它还提供一套与宿主模型、权限体系和扩展边界对齐的参考操作界面。

这能显著降低一个常见集成成本：团队不需要再额外把后端框架和另一套无关的后台 UI 拼在一起。
