Use the channel that matches the kind of discussion you need.

| Channel | Best for |
| --- | --- |
| `GitHub Issues` | Reproducible bugs, feature requests, documentation corrections, and public technical decisions. |
| `QQ` group | Chinese real-time discussion and quick usage questions. |
| WeChat group | Chinese community communication and project updates. |
| `Discord` | International real-time discussion. |

## Public Problem Reports

Prefer `GitHub Issues` when the discussion should be searchable later. Real-time groups are useful for clarification, but decisions and reproducible defects should be recorded in the repository.
