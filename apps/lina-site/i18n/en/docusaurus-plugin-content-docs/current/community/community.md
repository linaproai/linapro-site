## Before Asking For Help

For faster feedback, include the following when reporting a problem:

1. The `LinaPro` version or Git branch.
2. The command you ran, such as `make init`, `make mock`, or `make dev`.
3. The affected module, for example `lina-core`, `lina-vben`, or `lina-plugins`.
4. Relevant logs or screenshots with secrets removed.
