`LinaPro`'s long-term maintenance depends on real-world usage feedback from production projects.

## Meaningful Ways to Help

| How to help | Why it matters |
| --- | --- |
| File reproducible issues | Keeps the framework reliable across different environments. |
| Improve documentation and examples | Lowers the barrier for new users. |
| Share production experiences | Keeps architectural decisions grounded in real-world delivery. |
| Answer community questions | Helps the project scale beyond the core maintainers' available time. |
| Star or share the repository | Helps more developers discover the project. |

## Donation Channels

Donation details have not yet been finalized. Once official donation channels are ready, this page will be updated with the link and instructions.

In the meantime, the most effective support is concrete feedback, focused issue reports, documentation improvements, and contributions of working plugin examples.
