`LinaPro` depends on long-term feedback from developers who use the framework in real projects.

## Useful Support

| Support | Impact |
| --- | --- |
| Report reproducible issues | Helps keep the framework reliable across environments. |
| Improve docs and examples | Reduces onboarding cost for new users. |
| Share production feedback | Keeps architecture decisions grounded in real delivery work. |
| Answer community questions | Helps the project scale beyond core maintainers. |
| Star or share the repository | Makes the project easier for new developers to discover. |

## Donation Channels

Donation information is not finalized yet. When public donation channels are ready, this page will list the official entry points and usage notes.

Until then, the best support is concrete feedback, focused issues, documentation improvements, and practical plugin examples.
