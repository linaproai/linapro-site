## What To Expect

`LinaPro` is not only a project scaffold. It combines a `Go` core host, a `Vue 3` management workspace, an official plugin workspace, and an `OpenSpec` workflow that keeps requirements, code, and tests aligned.

For a first run, focus on these checkpoints:

1. The backend starts on `http://localhost:8080`.
2. The management workspace starts on `http://localhost:5666`.
3. The default account can sign in.
4. The plugin management page can list official plugins.
5. The `OpenAPI` page is available for contract inspection.

After these are working, move into the development manual and read only the area that matches your next task.
