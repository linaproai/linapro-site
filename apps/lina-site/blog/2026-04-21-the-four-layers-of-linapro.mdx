LinaPro is easiest to understand when you look at it as four cooperating layers.

{/* truncate */}

## 1. Core host service

The host owns contracts, governance, auth, permissions, and plugin lifecycle orchestration.

## 2. Management workspace

The workspace is a production-ready Vue 3 operator UI that mirrors host capabilities and provides a real starting surface for teams.

## 3. Plugin runtime

Source plugins and dynamic WASM plugins keep optional business capability out of the host while preserving a governed extension model.

## 4. OpenSpec workflow

The workflow keeps requirements, design, implementation, and review aligned over time.

That last layer is why LinaPro is not only a technical stack. It is a framework for AI-era delivery.
