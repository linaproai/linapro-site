`LinaPro`内置一组面向生产应用的基础能力，让团队可以从业务价值出发，而不是从基础设施接线开始。

## 宿主能力

| 领域 | 模块 |
| --- | --- |
| 权限管理 | 用户管理、角色管理、菜单管理和按钮级权限授权。 |
| 系统设置 | 数据字典、参数设置和文件管理。 |
| 任务调度 | 任务管理、任务分组、执行日志、处理器注册表、`Cron`预览和受控`Shell`执行。 |
| 扩展治理 | 插件管理、生命周期状态和版本可见性。 |
| 开发中心 | 在线`API`文档和运行时系统信息。 |

## 官方插件

| 插件 | 能力 |
| --- | --- |
| `org-center` | 部门管理和岗位管理。 |
| `content-notice` | 通知公告管理。 |
| `monitor-online` | 在线用户与强制下线。 |
| `monitor-server` | 服务监控和运行时资源查看。 |
| `monitor-operlog` | 操作日志落库与审计查询。 |
| `monitor-loginlog` | 登录日志落库与审计查询。 |
| `demo-control` | 演示环境只读保护。 |

## 实践原则

创建新模块前，先判断需求是否可以复用已有宿主能力、官方插件或扩展点。复用内置模型，可以让权限、菜单、日志和生命周期行为保持一致。
