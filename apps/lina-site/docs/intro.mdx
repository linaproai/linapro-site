# LinaPro

LinaPro is an **AI-driven full-stack development framework** for teams that want AI to accelerate delivery without letting architecture, requirements, and tests drift apart.

Instead of treating AI as a faster code editor, LinaPro treats it as a participant in a governed system:

- a **core host service** provides stable backend contracts and governance
- a **management workspace** provides a production-ready operational UI
- a **plugin runtime** keeps business modules optional and replaceable
- an **OpenSpec workflow** keeps specs, code, and review checkpoints aligned

## Why LinaPro exists

AI-assisted projects often ship quickly at the beginning and slow down later for the same reasons:

- context has to be rebuilt again and again
- architecture changes lose a stable baseline
- test intent stays in chat history instead of executable checks
- human review becomes the dominant bottleneck

LinaPro addresses that problem with a framework that is optimized for **AI-led, human-guided delivery**.

## The four layers

| Layer | Module | Role |
| --- | --- | --- |
| Core Host Service | `apps/lina-core` | Contracts, auth, permissions, governance, plugin lifecycle |
| Management Workspace | `apps/lina-vben` | Default Vue 3 operator workspace for built-in capabilities |
| Plugin Runtime | `apps/lina-plugins` | Source plugins and dynamic WASM plugins for extension and replacement |
| OpenSpec Workflow | `openspec/` | Explore, propose, implement, review, and archive in a spec-driven loop |
