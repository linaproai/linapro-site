# Getting Started

This repository serves the LinaPro official site. Its local boot flow is intentionally small: install the workspace dependencies when needed, then start the Docusaurus development server.

:::note Prerequisite
Make sure `pnpm` is available locally. The `make dev` target will install workspace dependencies automatically if they are missing.
:::

## Canonical boot flow

```bash
make dev
```

## What these commands do

- `make dev`
  Starts the LinaPro official site in development mode.

## Default local addresses

- Official site: `http://localhost:3000`

## Useful follow-up commands

```bash
pnpm typecheck
pnpm build
```

## Evaluation checklist

After the system starts, confirm these basics:

- the homepage loads successfully
- docs, blog, About, login, and register routes are reachable
- locale switching works as expected
- local search and static assets behave correctly

Once you have the environment running, continue with [Architecture](/docs/architecture).
