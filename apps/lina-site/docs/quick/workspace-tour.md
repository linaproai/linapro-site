登录`http://localhost:5666`后，建议先浏览管理工作台，确认`LinaPro`已经内置哪些能力，再决定业务模块应该放在宿主、源码插件还是动态插件中。

## 内置区域

| 区域 | 建议检查内容 |
| --- | --- |
| 权限管理 | 用户、角色、菜单以及按钮级权限，均已接入后端`RBAC`。 |
| 系统设置 | 字典、运行时参数和文件管理。 |
| 任务调度 | 任务定义、任务分组、执行历史和受控`Shell`执行。 |
| 扩展中心 | 插件安装状态、启用状态、停用状态和版本信息。 |
| 开发中心 | 在线`API`文档和运行时系统信息。 |

## 官方插件模块

仓库内置的官方源码插件位于`apps/lina-plugins/`。这些插件通过生命周期注入菜单和路由，而不是把功能代码散落在宿主内部。

| 插件 | 工作台能力 |
| --- | --- |
| `org-center` | 部门管理与岗位管理。 |
| `content-notice` | 通知公告管理。 |
| `monitor-online` | 在线会话查看与强制下线。 |
| `monitor-server` | 服务资源与运行时监控。 |
| `monitor-operlog` | 操作审计日志。 |
| `monitor-loginlog` | 登录审计日志。 |

## 首次检查建议

1. 打开权限管理，确认默认管理员角色已分配菜单和操作权限。
2. 打开扩展中心，查看官方插件列表。
3. 打开`API`文档页面，检查一个受保护接口的契约。
4. 在阅读开发手册前，不建议修改面向生产环境的配置。
