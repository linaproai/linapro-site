`LinaPro`的长期维护离不开真实项目中的使用反馈。

## 有价值的支持方式

| 支持方式 | 价值 |
| --- | --- |
| 反馈可复现问题 | 帮助框架在不同环境中保持可靠。 |
| 改进文档和示例 | 降低新用户上手成本。 |
| 分享生产实践 | 让架构决策持续贴近真实交付。 |
| 回答社区问题 | 帮助项目突破核心维护者的时间限制。 |
| 点亮或分享仓库 | 让更多开发者发现项目。 |

## 捐赠渠道

捐赠信息尚未最终确定。官方捐赠渠道准备完成后，本页会补充入口和使用说明。

在此之前，最有效的支持是提供具体反馈、提交聚焦的问题、改进文档，以及贡献可运行的插件示例。
