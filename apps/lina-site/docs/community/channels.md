请根据问题类型选择合适的交流渠道。

| 渠道 | 适合内容 |
| --- | --- |
| `GitHub Issues` | 可复现缺陷、功能建议、文档修正和公开技术决策。 |
| `QQ`群 | 中文实时交流和快速使用问题。 |
| 微信群 | 中文社区沟通和项目动态。 |
| `Discord` | 国际化实时交流。 |

## 加入方式

| 渠道 | 入口 |
| --- | --- |
| `QQ`群 | ![`QQ`群二维码](/img/community/qq-group-qrcode.svg) |
| 微信群 | ![微信群二维码](/img/community/wechat-group-qrcode.svg) |
| `Discord` | [加入`Discord`频道](https://discord.gg/Hyn5qxPwg) |
| `GitHub Issues` | [提交`issue`](https://github.com/linaproai/linapro/issues) |

`QQ`群和微信群二维码当前使用占位图片，后续可直接替换对应静态资源。

## 公开问题建议

如果问题需要后续检索，优先使用`GitHub Issues`。实时群适合澄清背景，但可复现缺陷和关键决策应沉淀到仓库中。
