A workspace ready to use on day one

Start with a ready-to-use admin workspace, then extend or replace modules as your product grows.

Up and running in three commands

Install, initialize, and run the default workspace in minutes.

INSTALL
git clone --depth 1 https://github.com/linaproai/linapro.git linapro
INITIALIZE
make init confirm=init
make mock confirm=mock   # optional demo data
DEVELOP
make dev
# Workspace: http://localhost:5666
# API:       http://localhost:8080
