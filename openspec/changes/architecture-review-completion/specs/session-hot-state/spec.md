## ADDED Requirements

### Requirement: 会话热存储只保留写读删续期

系统 SHALL 让会话热存储契约只包含写入、读取、删除和续期（以及认证所需的按用户删除）。带数据权限的在线用户列表、计数和清理 MUST 放在管理投影上。热路径构造函数 MUST 返回热存储契约，不得把管理投影类型当作热路径依赖。

#### Scenario: 认证续期会话

- **WHEN** 请求通过认证中间件续期
- **THEN** 只调用热存储的读/写/删/续期
- **AND** 不需要列表或计数方法

#### Scenario: 在线用户管理列表

- **WHEN** 管理员查询在线用户
- **THEN** 查询走管理投影并在数据库侧注入数据权限
- **AND** 该列表方法不属于热存储核心契约
