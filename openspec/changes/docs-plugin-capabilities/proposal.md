## Why

官网现有插件系统文档（`5000-plugin-system/`）介绍了插件治理主链、生命周期、目录结构和`pluginhost`注册机制，但缺少对主框架向插件暴露的基础能力服务（`capability.Services`）的系统性介绍。插件开发者在使用`registrar.Services()`获取`Config()`、`Auth()`、`TenantFilter()`等服务时，缺乏架构层面的设计说明，难以理解各服务的定位、边界和协作关系。

## What Changes

- 在`apps/lina-site/docs/docs/2000-components/5000-plugin-system/`下新增`6500-capabilities/`子目录
- 创建总览文档`6500-capabilities.md`，介绍`Services`接口架构、获取方式、服务分类速查和按场景选服务指南
- 为`capability.Services`的16个服务方法和`pluginhost.Services`扩展的`TenantFilter`共17个服务各创建一篇架构设计文档（`6600-apidoc.md`至`8000-tenant-filter.md`）
- 文档定位为架构设计文档，侧重设计思路、架构位置和设计约束，主要方法简要说明为辅
- 仅创建中文文档，英文翻译后续单独处理
- `ConfigService`和`HostConfigService`合并为一篇文档（`7000-config.md`）
- `orgcap.Service`和`tenantcap.Service`文档额外包含提供方`Provider`实现指引

## Capabilities

### New Capabilities

- `plugin-capabilities-overview`：`Services`接口总览，包含架构图、获取方式、17个服务的分类速查和按场景选服务指南
- `plugin-capability-apidoc`：`APIDocService`架构设计——API文档本地化服务的设计动机、操作键构建机制和在请求链路中的位置
- `plugin-capability-auth`：`AuthService`架构设计——认证Token交接服务的两阶段模型、模拟令牌治理边界
- `plugin-capability-bizctx`：`BizCtxService`架构设计——业务上下文投影服务的设计约束和与请求链路的关系
- `plugin-capability-cache`：`CacheService`架构设计——插件作用域缓存的隔离策略和过期机制
- `plugin-capability-config`：`ConfigService`与`HostConfigService`架构设计——插件配置与宿主配置的读取优先级和边界划分
- `plugin-capability-i18n`：`I18nService`架构设计——运行时翻译服务的设计和翻译键命名约定
- `plugin-capability-manifest`：`ManifestService`架构设计——插件清单资源服务的路径语义和资源管线边界
- `plugin-capability-notify`：`NotifyService`架构设计——通知服务的发布模型和收件箱分类
- `plugin-capability-org`：`orgcap.Service`架构设计——组织能力的消费侧只读接口和提供方`Provider`扩展机制
- `plugin-capability-plugin-lifecycle`：`PluginLifecycleService`架构设计——插件生命周期编排服务在租户级治理中的角色
- `plugin-capability-plugin-state`：`PluginStateService`架构设计——插件启用状态查询的本地快照与权威读取策略
- `plugin-capability-route`：`RouteService`架构设计——动态路由元数据服务的设计和与动态插件的关系
- `plugin-capability-session`：`SessionService`架构设计——在线会话管理服务的设计和会话投影模型
- `plugin-capability-tenant`：`tenantcap.Service`架构设计——租户能力的消费侧接口和提供方`Provider`/`Resolver`扩展机制
- `plugin-capability-tenant-filter`：`TenantFilterService`架构设计——租户过滤服务的数据库查询注入模式和与`pluginhost.Services`的关系

### Modified Capabilities

（无现有能力的需求变更）

## Impact

- 新增文件：`apps/lina-site/docs/docs/2000-components/5000-plugin-system/6500-capabilities/`目录下的17个`.md`文件
- 侧边栏自动发现：`sidebars.ts`使用`autogenerated`，新增目录会自动纳入`docsSidebar`
- 与现有文档的关联：`6000-source-plugins.md`中已提及的`HostServices()`、`Config()`、`HostConfig()`、`Manifest()`等内容将在新文档中得到深入展开，新文档将与现有文档互相链接
- 无代码变更、无依赖变更、无破坏性影响
