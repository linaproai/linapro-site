## ADDED Requirements

### Requirement: 组织与租户启用态必须是明确能力标志

系统 SHALL 通过明确能力标志表达组织管理和租户管理是否对当前会话启用。前端壳 MUST 使用这些标志决定相关 UI 是否显示。系统 MUST NOT 把菜单路径、菜单名称或`Tenant`前缀作为能力是否启用的事实源。

#### Scenario: 租户插件启用后壳打开租户能力

- **WHEN** `tenant.management`或等价租户能力已启用
- **THEN** 身份或能力接口返回租户已启用标志
- **AND** 默认工作台根据该标志显示租户相关壳行为

#### Scenario: 组织插件禁用后壳隐藏组织能力

- **WHEN** 组织管理能力未启用
- **THEN** 能力标志为未启用
- **AND** 工作台隐藏组织相关字段、筛选项和导航，而不是从菜单树猜测
